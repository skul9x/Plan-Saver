Status: ✅ Completed

## Objective
Xây dựng giao diện người dùng bằng Svelte.

## Requirements
### Functional
- [ ] Ô nhập liệu (Textarea) chiếm phần lớn màn hình.
- [ ] Nút "Paste & Extract" chính.
- [ ] Khu vực hiển thị thư mục đang được chọn.
- [ ] Nút "Change Folder".

### Non-Functional
- [ ] UI hiện đại, premium (vibe coding).
- [ ] Hiệu ứng hover, transition mượt mà.
- [ ] Responsive layout.

## Implementation Steps
1. [ ] Thiết kế Layout chính với Svelte components.
2. [ ] Sử dụng CSS cho các hiệu ứng glassmorphism hoặc dark mode.
3. [ ] Tạo component cho Textarea và Buttons.
4. [ ] Hiển thị thông báo (Toast/Alert) khi lưu thành công hoặc có lỗi.
